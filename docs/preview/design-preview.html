关键改动 逐屏玻璃化

  • 聊天气泡：用户=主色实心（iMessage 蓝），AI=中性玻璃；不对称大圆角尾尖；思考/代码/公式块用玻璃容器
  • 顶栏 / 输入栏：真背景模糊（Android RenderEffect，API31+；低版本回退半透明），胶囊输入 + 圆形发送
  • 底栏：浮动玻璃胶囊，选中项主色药丸高亮
  • 角色页：玻璃卡片网格，字母 monogram 渐变头像，使用中主色描边
  • 设置页：iOS 分组列表（section header + 分组卡 + 行间分隔 + 开关 / 箭头）
  • 音乐页：玻璃正在播放卡 + 歌词聚焦 + 圆形播放 + 列表行
  • 启动页：替换 RHODES 启动屏为极简玻璃 logo + 进度
