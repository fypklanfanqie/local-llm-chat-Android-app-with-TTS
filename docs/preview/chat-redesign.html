聊天界面重设计要点 紫罗兰

  • 气泡：用户=品牌色实心（带光晕）、AI=品牌色调玻璃；暗色模式下 AI 气泡不再使用中性灰，而是带当前主色的半透明玻璃，17dp 不对称大圆角尾尖
  • 去灰留玻璃：顶栏 / 输入栏 / 抽屉等玻璃容器改用带品牌色调的边框与微 tint 背景，文字次要色从冷灰调整为暖灰紫调，避免暗色下发闷
  • 深度思考：品牌色调玻璃容器，可点击展开/折叠，箭头旋转；流式时默认展开、完成后折叠
  • 代码块：独立深色面板（亮暗皆然）+ 语法高亮 + 语言标签 + 复制按钮，与正文气泡区分
  • 图片附件：圆角缩略图嵌入气泡；输入栏上方附件预览条可单独移除
  • 欢迎态：大头像 + 角色简介 + 推荐话题药丸，空对话不再空旷
  • 操作胶囊：复制 / 朗读 / 重生成（仅 AI），复制后变绿「已复制」
  • 字幕条：TTS 朗读时浮于输入栏上方，中日双语
  • 会话抽屉：玻璃底部弹层 + 遮罩，列表项含头像/标题/时间/消息数，重命名·删除
  • 顶栏：头像+在线点+角色名/定位，云端/本地分段，思考·会话·更多图标
